# 验证说明

## 自动化覆盖

- 协议：合法状态、严格拒绝敏感扩展字段；
- 状态机：四档阈值、优先级、瞬态超时、跨午夜和 App Server/Hook 去重；
- 服务端：注册、配对、重复认领、五次尝试限制、快照、解除配对和乱序序号；
- Hook：输入包含 Prompt、路径、命令和回复时，输出只保留四个允许字段；
- Rust：Hook sidecar 隐私序列化、桌面状态聚合和 Tauri 编译。
- App Server：官方状态值、审批、审批解除、未知事件与向前兼容字段；
- WebSocket：两个真实客户端的配对、P95 同步、隐私状态、快照恢复与解除配对；
- PostgreSQL：真实数据库中的配对事务、序号防回退和快照撤销。

本地受限沙盒可跳过监听端口与 PostgreSQL 用例。完整 CI 设置：

```bash
RUN_NETWORK_E2E=1 pnpm --filter @petlink/sync-server test
TEST_DATABASE_URL=postgres://petlink:petlink@127.0.0.1:5432/petlink_test \
  pnpm test:integration
```

## 双机人工验收

1. 在两台设备启动同一同步服务地址；
2. A 生成配对码，B 输入并连接；
3. A 模拟五种任务状态，确认 B 在 2 秒内更新；
4. 关闭 A 网络，确认 B 先显示重连、60 秒后离线；
5. 恢复网络，确认 10 秒内恢复；
6. 关闭精力共享，确认 B 不再收到精力值；
7. 开启隐私暂停，确认 B 只看到隐身；
8. 解除配对，确认双方快照清除且旧令牌不能继续读取好友状态。

## 平台人工验收

macOS 与 Windows 各自检查：透明度、拖动、置顶、托盘显示/隐藏、位置恢复、多显示器边界、减少动态、安装/卸载插件、`/hooks` 信任提示及未签名测试包的系统警告。
