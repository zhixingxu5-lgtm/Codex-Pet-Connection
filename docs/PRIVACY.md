# 隐私说明

## 会离开设备的数据

- 随机设备 ID；
- 单调递增序号；
- 在线、重连、离线或隐私暂停状态；
- 抽象任务状态；
- 用户允许共享时的四档精力；
- 更新时间、过期时间及一次性动画 ID。

## 不会读取或同步的数据

Prompt、模型回复、代码、文件路径、项目名、命令、工具输入、命令输出和 Codex 会话正文。
Hook sidecar 会在本地丢弃这些字段，协议验证器也拒绝额外字段。

## 保留与删除

- 本地只保存当天累计运行秒数、设置、窗口位置和最后设备身份；跨本地午夜重置工作量。
- 服务端只保存当前设备、配对关系和状态快照，不保存每日工作量历史。
- 解除配对后立即删除双方快照和房间关系。
- 隐私暂停时仅发送 `presence: privacy_hidden`，任务和精力均为 `null`。
