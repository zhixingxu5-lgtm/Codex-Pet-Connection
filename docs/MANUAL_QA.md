# macOS / Windows 人工验收表

每个平台、每个候选安装包都必须单独记录结果。

## 安装与窗口

- [ ] 在未安装开发工具的干净系统完成安装和首次启动；
- [ ] 设置窗口、我的 Pingu、好友 Pingu 同时出现；
- [ ] 两只桌宠可分别拖动与缩放，保持透明、无边框和置顶；
- [ ] 跨显示器移动后重启，位置恢复且不会留在已断开的屏幕外；
- [ ] 托盘可显示/隐藏、切换隐私/精力/减少动态、打开诊断和退出；
- [ ] 系统减少动态和应用减少动态均冻结循环动画。

## Codex 与状态

- [ ] 插件可安装与卸载，`/hooks` 显示预期命令并可信任；
- [ ] App Server 正常时识别 running、needs_input、ready、blocked 和 interrupted；
- [ ] App Server 不可用时显示有限检测，Hooks 仍可驱动状态；
- [ ] `ready` 三十秒回到 idle，`blocked` 五分钟回到 idle；
- [ ] 两个并行任务只累计一份墙钟时间，跨本地午夜清零。

## 双机同步

- [ ] 配对码八位、十分钟失效，一台设备只能有一名好友；
- [ ] 状态 P95 两秒内到达，断网六十秒内显示离线；
- [ ] 恢复网络十秒内自动恢复并读取快照；
- [ ] 关闭精力共享后好友收到 `energyState: null`；
- [ ] 隐私暂停后好友只看到隐身；
- [ ] 解除配对后双方旧快照不可访问。

## 性能与安全

- [ ] 连续空闲十分钟平均 CPU 低于 3%；
- [ ] 桌面进程稳定内存低于 200 MB；
- [ ] 网络抓包不包含 Prompt、回复、代码、路径、项目名、命令或工具内容；
- [ ] SHA-256 与 Release 中的校验文件一致。
